SARMIS privacy policy

Last updated 25 November 2026

Who uses it

SARMIS is a personal assistant used by one person only, its owner, Marius Manea. It connects only Google accounts that belong to the owner, and only after he signs in and consents on Google's own page.

What it accesses

  • Gmail: reads messages, and sends a message only after the owner approves that exact message.
  • Google Calendar: reads events, and creates or changes an event only as the owner's settings and approvals allow.
  • Google Drive: reads files, and creates files only when the owner asks for one.

Where the data is kept

Data received from Google is stored on the owner's own server, in an encrypted folder. It is not stored on any third-party service by SARMIS.

Who it is shared with

The data is never sold, never used for advertising, and never shared with anyone else. To answer the owner's own questions, short parts of it may be sent to the AI model provider the owner has configured (Anthropic), through the owner's own API account. That is the only transfer, and it only serves features the owner uses himself.

SARMIS's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The owner can revoke SARMIS's access at any time at myaccount.google.com/permissions, and can erase the stored data from his own server.
