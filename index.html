Synthetic-data drone detection

A real-time drone detection model trained entirely on synthetic data, so it doesn't depend on real aerial footage, which is expensive and hard to get.

I built a Unity simulation pipeline over a full 3D model of Hong Kong that generates auto-annotated images across different altitudes, lighting and weather, then benchmarked how well the model generalises to real scenes it hasn't seen.
